Predictions:

using what we've learned from lecture 12, size = parameter x bits per weight / 8 bytes. that said llama3.2:1b should have about 1.24 billion paramters while using Q8_0, which would be 8 bits per weight.

using what wek know and the formula, we can predict that 1.24bil x 8 / 8 = approximately 1.24GB. With that said, we can also see that the actual value was 1.3GB (reported). The prediction is close, but the actual file is bigger since ti doesn't only hold the weights, it's also used to store tokeniser and metadata.
